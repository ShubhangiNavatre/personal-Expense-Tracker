# Personal Expense Tracker

## About the Project

Personal Expense Tracker is a simple Python project used to record and manage daily expenses.

## Features

- Add expenses
- Store expense details in a CSV file
- View recorded expenses
- Track spending easily

## Technologies Used

- Python
- CSV file

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Run the following command:

```bash
python expense_tracker_new.py
